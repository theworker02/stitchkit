# stitchkit

Stitch identifiers and kit tokens for idempotent workflows.

**Site:** https://theworker02.github.io/stitchkit/

## Install / run

```bash
git clone https://github.com/theworker02/stitchkit.git
cd stitchkit
node src/cli.js
node --test
```
